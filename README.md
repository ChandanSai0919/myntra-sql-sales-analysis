# Myntra SQL Sales Analysis

SQL-based analysis of Myntra sales data to uncover trends in revenue, product categories, customer behavior, and order patterns.

## Tech Stack
SQL (Microsoft SQL Server / T-SQL), data cleaning, aggregations, joins, window functions

## Contents
- Data exploration and cleaning queries
- Sales trend and revenue analysis
- Top categories, brands, and customer segments
- Key business insights with supporting queries

## How to Run
1. Import the dataset into MySQL (or your SQL tool)
2. Run the .sql scripts in order

## Dataset
Myntra sales dataset (included in this repository if under size limits).
